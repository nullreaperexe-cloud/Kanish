# ClassPing Firestore Schema

## events/{eventId}
Generated by the trusted GitHub Action.

- type: test, notebook_submission, homework, assignment, project, exam, practical, important, other
- subject: canonical subject name
- title: short student-facing title
- topic: syllabus/chapter/exercise/item
- eventDate: Firestore timestamp or null
- dateLabel: original day/date wording when useful
- priority: high or normal
- needsReview: true when date/details are uncertain
- source: edusecure
- sourceMessageId: deterministic message hash
- published: true
- status: active
- className: 8
- section: A

The Android Test Table is a query over events where type == test.
Notebook submissions use type == notebook_submission.

## source_messages/{sourceMessageId}
Used for deduplication and audit. States: pending_ai, done, ignored.

## automation_logs/{runId}
Run counts only; workflow logs avoid printing raw school messages.

## users/{uid}
Per-student profile and reminder preferences written by the Android app.

## app_config/main
Global app settings already created in Firebase Console.
